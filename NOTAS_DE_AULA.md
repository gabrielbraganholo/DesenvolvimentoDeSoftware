## Java Swing

### Descrição

O **Java Swing** é uma biblioteca gráfica da linguagem Java utilizada para o desenvolvimento de interfaces gráficas de usuário (GUI - *Graphical User Interface*). Ela fornece diversos componentes, como botões, menus, tabelas e campos de texto, permitindo a criação de aplicações desktop multiplataforma.

### Vantagens

- **Plataforma independente:** as aplicações Swing funcionam em diferentes plataformas sem a necessidade de reescrever o código.
- **Componentes personalizados:** é possível personalizar a aparência e o comportamento dos componentes Swing para atender às necessidades específicas da aplicação.

### Desvantagens

- **Aparência e experiência do usuário:** o Java Swing não apresenta uma aparência nativa em todas as plataformas.
- **Desempenho:** aplicações desenvolvidas com Swing podem apresentar desempenho inferior ao de interfaces gráficas nativas, especialmente em aplicações mais complexas.
